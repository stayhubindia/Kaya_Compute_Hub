# Frontend Library & Utilities (`/lib`)

This directory contains client-side helper modules and abstractions:

- **`api/`**: HTTP client wrappers, REST fetchers, and WebSocket/SSE log streaming handlers.
- **`auth/`**: Authentication state management, cookie resolution, and session helpers.
- **`config/`**: Environment variable parsing and global application constants.
- **`schemas/`**: TypeScript Zod validation schemas for forms, API responses, and job configuration payloads.
