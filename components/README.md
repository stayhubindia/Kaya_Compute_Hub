# Frontend UI Components (`/components`)

This directory contains modular React/Next.js components structured by domain:

- **`layout/`**: Structural shell components including navigation header, sidebar, footer, and page layout containers.
- **`shared/`**: Reusable design system primitives such as buttons, modals, cards, data tables, status badges, and spinners.
- **`features/`**: Feature-specific UI modules (e.g., job submission forms, worker status cards, log streaming viewers, dataset file browsers).
