# Documentation Directory (`/docs`)

This directory contains technical documentation for Kaya Compute Hub:

- **`ARCHITECTURE.md`**: Master architecture specification, component breakdown, job lifecycle state machine, recovery mechanics, and security baseline.
- **`adr/`**: Architecture Decision Records (ADRs) capturing major architectural choices and rationale.
- **`runbooks/`**: Operational runbooks for deployment, database backup/restore, VM recovery, and maintenance routines.
